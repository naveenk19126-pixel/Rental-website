# 🏠 RentEase – Rental E-Commerce Website

RentEase is a modern rental e-commerce website that allows users to rent products instead of buying them.

## 🚀 Features

- 🔐 User Registration & Login
- 🔍 Product Search
- 🏷️ Category Filtering
- 💻 Electronics Rentals
- 🏍️ Bike Rentals
- 📚 Book Rentals
- 🛋️ Furniture Rentals
- 🎉 Event Item Rentals
- 📅 Rental Start & End Date
- 🧮 Automatic Rental Price Calculation
- 💰 Security Deposit Calculation
- 📦 Booking Management
- ❌ Cancel Rental
- 💾 LocalStorage Data Management
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 📂 Categories

- Electronics
- Bikes
- Books
- Furniture
- Event Items

## 🔄 User Flow

Home
→ Products
→ Product Details
→ Select Rental Dates
→ Calculate Price
→ Book Product
→ My Rentals
